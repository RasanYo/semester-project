# specs

Une spec par feature, lue en entier par Ralph avant la première ligne de code.
Écrite à la main, ou générée par `ralph-import <fichier>` depuis un PRD, une
issue ou un document de conception.

Une spec utile porte le contrat exact — schémas, formules, disposition des
fichiers, critère d'acceptation — pas l'intention générale : ce qui reste flou
ici sera tranché par la boucle, sans toi.
