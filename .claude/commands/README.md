# commands

Commandes slash Claude Code pour les workflows de ce repo.

## Architecture

- `devlog.md` — rédige une entrée `DEVLOG.md` pour un lot de travail terminé
- `doc.md` — génère le README d'un dossier
- `explore.md` — exploration profonde : codebase, docs, web
- `oneshot.md` — implémentation rapide d'une feature (explore → code → test)
- `git/` — commit, create-pr, create-issue-and-branch, fix-pr-comments

## Usage

```
/devlog
/doc src/data
/explore <sujet>
/oneshot <feature>
/git:commit
/git:create-pr
```
